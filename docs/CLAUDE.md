# Docs rules
- Evidence only: every claim about tests, findings or timings links to a command output, commit, PR or file.
- Never invent prompts, findings, corrections or numbers. If a step was skipped, write "not done" and why.
- Phase files follow the template in `docs/progress/_TEMPLATE.md`. Leave the "Human review" section empty.
- `docs/ai/PROMPTS.md` entries are verbatim, tagged `human→agent` or `agent→subagent`, with purpose and outcome.
- ADRs use `docs/adr/_TEMPLATE.md` and record who decided.
- Plain, normal English. Short sentences. No marketing language.
